# Security Policy

## Reporting a Vulnerability

If you find a security issue, please do not open a public issue with full exploit details.

Instead, report it privately to the repository owner.

Suggested contact:

`brw.sudheer@gmail.com`

## What to Include

- short summary of the issue
- affected file or feature
- steps to reproduce
- possible impact
- any suggested fix

## Response Goal

The goal is to review serious reports as quickly as possible and fix confirmed issues before full public disclosure.
